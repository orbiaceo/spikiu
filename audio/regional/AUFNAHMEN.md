# Aufnahmen für den Raum „Regional" (Leo, 15./16.10.2026)

Leo: „… con ejemplos de pronunciación que **debemos grabar**." — echte Sprecher aus der Region,
keine synthetische Stimme. Bis eine Datei da ist, zeigt der Raum „🎙️ Aufnahme folgt".

## Wo die Dateien hingehören
`audio/regional/<zielsprache>/<datei>` — der Dateiname steht in `aufnahmeliste.csv`
(Spalten: datei · region · text · art). Beispiel: `audio/regional/es/movil-mexico.mp3`.
Sobald die Datei im Repo liegt, spielt der 🔊-Knopf sie ab — kein Code nötig.

## Format
- MP3, mono, 44,1 kHz, 96–128 kbit/s; Stille am Anfang/Ende ≤ 0,3 s; Lautheit ca. −16 LUFS.
- Ein Wort / eine kurze Wendung pro Datei, natürlich gesprochen (nicht überdeutlich).
- Sprecher: aufgewachsen in der Region; Einverständnis zur Nutzung schriftlich festhalten.

## Umfang
Je Sprache die verschiedenen Formen der Begriffe + 8 Aussprache-Erscheinungen × 2–4 Beispiele
(genaue Zahl in der jeweiligen `aufnahmeliste.csv`). Jedes Wort nur EINMAL je Karte (Leo 16.10.:
Kontrast statt Wiederholung) — eine Aufnahme je verschiedener Form, Sprecher aus der ersten genannten Region.
